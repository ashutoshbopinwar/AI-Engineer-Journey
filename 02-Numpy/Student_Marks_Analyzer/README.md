
# 🎓 Student Marks Analyzer

A beginner-friendly Python + NumPy project that analyzes student marks and generates a detailed marksheet.

---

## 📌 Project Description

Student Marks Analyzer is a console-based application built using **Python** and **NumPy**. It stores students' marks in multiple subjects, performs calculations, assigns grades, and generates a formatted marksheet.

This project was created to strengthen my understanding of **NumPy arrays**, **data analysis**, and **Python programming**.

---

## 🚀 Features

- 📋 Display all students
- 📚 Store marks using NumPy arrays
- 👤 Select a student
- 📊 Calculate total marks
- 📈 Calculate average marks
- 📉 Calculate percentage
- 🏆 Find highest subject marks
- 📉 Find lowest subject marks
- 🎖️ Assign grades (A+, A, B, C, D, F)
- ✅ Pass/Fail result
- 📝 Generate a professional marksheet
